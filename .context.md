# Project Context for Manga AutoScan Translator

## Project Goal
Build a lightweight local manga/comic screen translation system using a Chrome extension frontend and a local Python backend. The extension captures a screen region, sends it to the local server for OCR and LLM translation, then overlays translated text on the page.

## Architecture
- `extension/` contains the Chrome MV3 extension UI and capture logic.
- `server/` contains Python FastAPI endpoints, OCR pipeline, and translation prompt handling.
- `README.md` documents setup and how to run the system.

## Main Data Flow
1. User selects a region or starts auto-scan in the Chrome extension.
2. `extension/content.js` captures the visible tab image via `background.js` and crops the selected region.
3. The extension sends a JSON payload to `server/main.py` at `/api/translate-image`.
4. `server/ocr.py` performs PaddleOCR and merges boxes into text lines.
5. `server/translate.py` builds an Ollama prompt, translates lines, and caches results.
6. The extension renders translated text overlays and optionally uses cleaned/inpainted background imagery.

## Naming Conventions
- `camelCase` for extension variables and functions in JavaScript.
- `snake_case` for Python functions and variables.
- `server/main.py` defines API endpoints with Pydantic request models.
- `extension/content.js` contains UI state and scan loop logic.

## Key Files
- `extension/manifest.json` — Chrome extension metadata and permissions.
- `extension/background.js` — handles capture requests and tab messaging.
- `extension/content.js` — core UI, region selection, scan queue/cache, server communication, overlay rendering.
- `server/main.py` — FastAPI server and translation image endpoint.
- `server/ocr.py` — image decoding, OCR, text grouping, and optional inpainting.
- `server/translate.py` — prompt construction, Ollama API calling, translation memory.

## Practical Notes
- DPI scaling is handled in the extension by mapping capture coordinates through `window.devicePixelRatio`.
- Local storage stores glossary, character names, and translation memory, but caches are limited to avoid growing indefinitely.
- The extension uses a queue to prevent overlapping server requests and a buffer scan mechanism to reduce repeated captures.
